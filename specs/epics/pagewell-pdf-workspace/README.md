# Epic: pagewell-pdf-workspace (PW)

**PdfCraft's engine, Acrobat's cloud, and an MCP server for every org, free on
Cloudflare. PdfCraft is a capable single-user PDF editor in pure Rust that
already runs in the browser, but it has no accounts, no cloud, no sharing and
no agents. Pagewell keeps that engine and editor unchanged as a pinned
dependency and adds what teams pay Acrobat for: a drive per org, sharing,
live review, e-signature requests, heavy jobs off the browser, and agents.
The one idea that makes this possible: every PDF operation has one JSON tool
schema, taken from PdfCraft itself (`pdf-tools.json`), and runs in one of
three places: the editor's WebAssembly in the browser, a jailed container,
or a Worker. The chat, the remote MCP server and the public API therefore
share one tool surface.**

Pagewell is for small teams and organisations that read, mark up, share and
sign PDFs together and want their AI agents to do the same. When it ships, an
org can sign up, upload a PDF, edit it in the browser, share it with members,
guests or a link, review it together live, send it for signature, run OCR or
compression, ask questions across its documents with page citations, and let
Claude or any MCP client work on its files under the same permissions as a
person.
